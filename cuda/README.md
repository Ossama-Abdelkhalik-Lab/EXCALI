# CUDA prototype of EXCALI's zero-revolution path (unrun)

**Status: compiled, never run on a GPU.** No NVIDIA GPU was available, so GPU
throughput, occupancy at run time and memory behaviour are unmeasured. This
directory is a prototype for evaluation, not part of the library build.

## Contents

- `excali_zero_rev.cuh`: line-by-line C++ port of `excali_one` for `nrev = 0`
  (main `f5ca647`). Under nvcc its functions are `__device__`; otherwise they are
  plain inline host functions, so the same source is tested on the CPU.
  - Ported: `geometry` and `zero_rev_start` (parabola, near-parabolic series,
    `tabe`/`long_d` ellipses, `tabh` and large-`w` hyperbolas including `xi`),
    plus `fast_coordinate`, `rect_ratio` (kinds 0, 1, 2, -1, -2, with the exact
    node-hit guard), `fast_accept` and `velocities`.
  - Multiple revolutions return status -6.
- `excali_zero_rev.cu`: one thread per case; inputs in Fortran `(3,n)` layout;
  a host wrapper `excali_zero_rev_gpu`.
- `excali_tables_cuda.h`: generated by `tools/gen_cuda_tables.py`, which compiles
  EXCALI's own constants and `src/excali_tables.inc` and writes their exact bits.
  - The trig tables keep only the positive half (cos/cosh even, sin/sinh odd),
    which the generator checks bit for bit.
  - Tables go in `__constant__` memory by default, or in global memory with
    `-DEXCALI_TABLES_GLOBAL`.
- `test/`: host check against Fortran (`run_host_test.sh <csv>...`).

## Results (2026-11-26)

**Host check** (g++ 16 against gfortran 16, Apple M1, truth sets `zero_rev`,
`sweep_zero`, `dev`, `harness_mixed`, `adversarial`; 112,391 zero-revolution
rows):
- Statuses are identical on every row.
- With `-ffp-contract=off` on both sides, every velocity is bit-identical.
- With default contraction, the compilers fuse different multiply-adds:
  - 57% of cases are bit-identical;
  - relative differences are p99 5e-15 and max 3.6e-11 (zero_rev);
  - accuracy against the reference velocities is unchanged (zero_rev p99 2.76e-13
    vs Fortran 2.78e-13; max 3.37e-10 for both).

64; a static figure from the register count, not a measurement). Capping at
64–96 registers spills.
